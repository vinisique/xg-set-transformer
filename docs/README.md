## As três regras que sustentam tudo

1. **Nenhum código sem decisão aprovada** — você precisa poder defender cada
   escolha, e não se defende o que não se decidiu.
2. **Nenhum número no relatório sem ID de experimento** — se não tem ID, não
   existe.
3. **Toda afirmação vem marcada** com **[medido]**, **[literatura]**, **[curso]**
   ou **[palpite]** — para você saber no que confiar e o que questionar.
